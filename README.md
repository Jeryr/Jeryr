### 🚀 Engineering Philosophy & Focus

I approach software engineering as applied mathematics. I specialize in designing normalized database schemas, building secure REST APIs, and engineering automated testing pipelines that catch regressions before they hit production.

- 🔭 **Architecting:** An Enterprise-grade Hospital Management REST API using **Node.js, Express, TypeScript, and Prisma ORM**.
- 🛠️ **Testing:** Building end-to-end UI and API automation frameworks with **Cypress** and **PostgresSQL**.
- 🔒 **Securing:** Implementing JWT authentication, password hashing (bcrypt), and SQL-injection prevention.
